📑 사람 판정 기준 (참고용)
1. 저장 규칙 준수
  1. Configuration Management Plan 내 '3.2 Library Structure'에 맞게 산출물들이 저장되고 관리되고 있는지 확인
    Ex) System Requirement Specification이 SYS > [SYS.2]System Requirements Analysis > Template 폴더에 저장되었는지 확인
  2. Document Tracker의 경우, 하나의 Tracker 내 하나의 파일만 등재되었는지 확인
  3. Configuration Management Plan 내 '4.2.4 File Naming Rule'에 맞게 산출물들이 저장되고 관리되고 있는지 확인
    Ex) Configuration Management Plan과 같이 산출물 명으로만 입력해야 한다.
2. 버전 규칙 준수
  1. 첫 Edit 이후, Working Day 10일 이내 Version Up이 진행되지 않은 상태
  2. 일정한 주기 없이 업데이트되는 산출물의 경우, Release / Review Closed / Audit Closed 상태임에도 불구하고 Create Date가 진행되지 않은 상태
3. 문서 이력 기술 규칙 준수
  1. Configuration Management Plan 내 '4.2.6 History Description Rule'에 기재한 이력 작성 규칙에 따라 작성되었는지 확인
    단, Approved 상태의 버전은 문서 이력을 확인하지 않는다.
  2. PR/CR로 인해 수정된 경우, 해당 산출물의 수정사항에 맞는 PR/CR-ID가 기입되었는지 확인
4. 상태 규칙 준수
  1. 산출물의 Review Report가 업로드 되기 전, 대상 산출물의 상태가 Waiting for Approval 이전 상태인지 확인
  2. 산출물의 Review Report가 업로드 되었을 때, 대상 산출물의 상태가 Waiting for Approval 이후 상태인지 확인
